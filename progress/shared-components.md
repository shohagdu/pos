# Shared components

| # | Component | File(s) | Change | Pages affected | Status |
|---|---|---|---|---|---|
| 1 | App shell: sidebar | `app/layouts/Sidebar.tsx`, `app/layouts/AppLayout.tsx` | Sidebar is a slide-out menu below **lg** (1024) instead of md (768), so tablets get the full width (was ~450px of content at 768). | 2 | App shell: header | `app/layouts/AppLayout.tsx`, `features/notifications/NotificationBell.tsx`, `app/layouts/UserMenu.tsx` | ☰, New sale, language, bell and user menu are 44×44 below lg (were 36px). | 3 | Form fields | `styles/index.css` | Below lg every input/select/textarea is at least 16px, so iOS doesn't zoom in on focus. One unlayered CSS rule, so it covers hand-written inputs too; from lg the original `text-sm` applies again. | All forms, filters, POS, dialogs | Done |
| 4 | Tabs | `components/ui/Tabs.tsx`; `features/products/CatalogNav.tsx` and `features/users/UsersPage.tsx` now use it | Below lg the tabs stay on one line and scroll sideways (were wrapping into 2–3 rows on phones); 44px tall. | 5 | Dialog | `components/ui/Dialog.tsx` | Below sm it is a bottom sheet (full width, rounded top), body max 70svh, footer clear of the iPhone home bar; close button 44px. | All dialogs (payment, expense, receive goods, journal…) | Done |
| 6 | Card | `components/ui/Card.tsx` | Default padding 16px on phones, 24px from sm (was 24px everywhere). | Every Card | Done |
| 7 | DataTable | `components/ui/DataTable.tsx`, `lib/useMediaQuery.ts` | **Automatic cards:** below lg (or below xl with `tableFrom="xl"`), *or whenever the table is wider than its own frame* (narrow panels on laptops, measured with ResizeObserver), each row is a card built from the columns: first column (or `card: 'title'`) as the title, the last right-aligned column (or `card: 'amount'`) on the right, the rest as label/value pairs, header-less columns as the card's action row. `card={fn}` draws a card by hand; `cards={false}` keeps the table. Only one of table/cards is rendered (tests without matchMedia/layout keep the table). `showFrom` hides low-priority columns on smaller laptops. Table frame is `relative` so screen-reader-only text cannot widen the page. | All 55 files that use DataTable | Done |
| 8 | `table-stack` CSS | `styles/index.css` | For hand-written tables (inputs per row): below lg each row becomes a card; each `<td data-label>` shows its column name on the left; first cell is the title; totals rows (`tfoot`) and `tr.stack-pair` rows stay label + amount. | Sale return form, purchase return form, payment methods, account book, customer statement, audit log, stock adjustment form | Done |
| 9 | InfoTip (ⓘ help) | `components/ui/InfoTip.tsx` | Hidden bubble is `display:none` (an invisible absolutely-positioned bubble was making the product form 46px too wide at **every** size); when shown it opens towards the side with room and never exceeds the screen width. | Product form, settings, checkboxes with tips | Done |
| 10 | Grids | 57 files (see `pages/` notes) | `grid` containers that only set columns at a breakpoint (`grid gap-6 lg:grid-cols-…`) got an explicit `grid-cols-1` base. No change from each grid's breakpoint up. | 76 grids | Done |
| 11 | Table frames | 13 hand-written tables | `relative` on their `overflow-x-auto` frame (same sr-only leak as #7). | Dialog and report tables | Done |
| 12 | Dashboard KPI | `features/dashboard/widgets.tsx`, `DashboardPage.tsx` | Amounts wrap instead of being cut off with "…"; six KPI cards per row only from 2xl (1536), three before that. | `/` | Done |
